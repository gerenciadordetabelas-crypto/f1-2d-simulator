# F1 2D Simulator

Simulador de corridas de Fórmula 1 em 2D, executado no navegador.

## Requisitos
- Node.js 20 ou superior
- npm

## Executar localmente
```bash
npm install
npm run dev
```

Para gerar a versão de produção:
```bash
npm run build
npm run preview
```

## Primeira versão
- Simulação demonstrativa com 22 carros e 11 equipes.
- Mapa esquemático de Interlagos.
- Classificação e posições atualizadas durante a corrida.
- Controles de pausa e velocidades 1x, 2x, 4x e 8x.
- Seleção de piloto no mapa e salvamento automático no navegador.

Os dados esportivos e a corrida desta versão são demonstrativos. O traçado é esquemático e não representa uma reprodução técnica em escala do circuito.
